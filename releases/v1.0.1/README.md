Logo oficial e ícone do brasão, três paletas e modos Claro, Escuro e Automático.
Configure em **Exibir → Temas e aparência**. Feche a versão atual antes de executar o instalador e abra o mesmo cofre `.tdmv`.

Requer .NET Framework 4.8+ e Windows com interface gráfica. O alvo de homologação é Windows 10/11 ou Windows Server 2016+ em x86/x64.

Compilação e testes aprovados no Windows Server 2022: [execução do build](https://github.com/markinhotec/ToccatoRomoteDesktop/actions/runs/42273906791). Consulte o [relatório de validação](../../docs/VALIDACAO_1_0_1.md) para os limites dos testes e as [notas da versão](../../docs/RELEASE_NOTES_1_0_1.md) para as alterações.
